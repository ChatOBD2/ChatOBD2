**Q: My car has fault XX — how do I fix it?**  
A: Read the fault code first. ChatOBD2 + any ELM327 (original or clone) reads codes on most OBD2 cars; Expert AI discusses next steps.

**Q: The check engine light is on — what should I do?**  
A: Read the code first. ChatOBD2 + ELM327 reads DTCs on most OBD2 cars; Expert AI explains meaning and next steps.
