## Hardware (optional — build your own)

We do not publish cracked “clone hex” firmware. For makers:

| Kind | Link | Note |
|------|------|------|
| Open PCB for a real **ELM327 IC** | https://github.com/Spartelfant/ELM327-BT | Third-party (CC-BY-SA). Not Elm Electronics. You buy the chip. |
| Open MCU / schematic (compatible style) | https://github.com/endurodave/OBDII-Adapter-Software | MIT — not an Elm chip |
| Elm datasheet | https://www.elmelectronics.com/ | Official docs — we do not mirror PDFs |

Most cheap store dongles use **PIC-style clones** that still speak ELM AT commands. ChatOBD2 targets that **compatible** class — no brand lock.
